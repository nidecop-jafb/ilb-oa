# ilb-oa

Site dos estudantes de **Introducao ao Laboratorio (ILB)** — Licenciatura em
Fisica, IFMG campus Ouro Preto.

Publicado por `publicar_trilha_ilb.py`
(`3_Estudio/LFI_02_ILB_Introducao_ao_Laboratorio/Trilhas/_scripts/`).
Nao editar `t*/` a mao: sao copias geradas a partir dos OAs canonicos da
trilha. O texto de apresentacao do `index.html` mora no proprio publicador.

As imagens publicadas sao as derivadas `_web` (1200 px, ~200 KB); os originais
de 2-3 MB ficam so no repositorio-fonte.
